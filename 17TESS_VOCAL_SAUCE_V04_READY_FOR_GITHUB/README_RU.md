# 17TESS VOCAL SAUCE — v0.4 REFERENCE FIX

## Изменения

- Интерфейс визуально основан прямо на картинке-референсе, а не нарисован заново приблизительно. Файлы PNG пользовательского дизайна встроены в VST3 через JUCE BinaryData.
- Восемь эффектов остаются на своих местах, а девятый **COMPRESSOR** расположен внутри панели DETAIL SETTINGS, когда дополнительные настройки закрыты.
- Нажатие `+` открывает детальные параметры выбранного эффекта. Кнопка `+` у панели DETAIL SETTINGS закрывает настройки и снова показывает компрессор.
- Восстановлено поведение основных регуляторов примерно как в первой версии. Saturation усилен относительно первой версии примерно вдвое; Distortion без тройного усиления; Chorus сильно смягчён.
- **EQ: 6 точек**, свободное горизонтальное перемещение каждой на 30–16 500 Hz, вертикальное на **−36…+36 dB**; у каждой точки свой Q в тонких настройках.
- Компрессор: Threshold, Ratio, Attack, Release, Makeup. Основная ручка — степень применения компрессии.
- Нет заводских пресетов. Save/Load сохраняют все значения в `.17tesspreset`.

Важно: картинки интерфейса и код подготовлены, автономный DSP-тест пройден, но этот исходный проект ещё не был собран и открыт на Windows в Cubase. Для получения рабочей VST3 требуется сборка GitHub Actions и проверка в Cubase. При попадании в блок-лист смотри журнал Cubase. Не устанавливай предыдущие экспериментальные версии параллельно.

## Сборка в GitHub без Visual Studio на ПК

**Самый простой путь — новый репозиторий.**

1. Распакуй `17TESS_VOCAL_SAUCE_V04_REFERENCE_FIX_SOURCE.zip`.
2. В репозитории GitHub нажми `Add file → Upload files` и загрузи содержимое распакованной папки, включая `source`, `assets`, `CMakeLists.txt`.
3. Через `Add file → Create new file` создай `.github/workflows/build-win64.yml` **в корне репозитория**, если папка `.github` не загрузилась. Вставь туда прилагаемый файл `build-win64.yml`.
4. Нажми `Commit changes`.
5. Открой `Actions`. Workflow `Build 17TESS Vocal Sauce V0.4 Windows x64` может запуститься автоматически; если нет — нажми `Run workflow`.
6. После зелёного `Success` открой `Summary`, прокрути вниз к `Artifacts`, скачай `17TESS-VOCAL-SAUCE-V04-WIN64`.
7. Внутри будет ZIP с папкой `17TESS VOCAL SAUCE.vst3`. Скопируй **всю эту папку** в `C:\Program Files\Common Files\VST3\`. Перезапусти Cubase.

**Для старого репозитория** нужно заменить не только `.cpp`, но и файлы `.h`, `CMakeLists.txt`, добавить папку `assets` и актуальный YAML. Если в репозитории лежит несколько старых проектов одновременно, workflow будет предпочитать папку с `V04_REFERENCE_FIX` в имени.

## Тестирование после сборки

1. Вставь плагин на дублированную вокальную дорожку, уменьшив громкость мониторинга.
2. Проверь, что все регуляторы в нейтральном состоянии пропускают звук без изменений.
3. Проверь Saturation, Chorus по отдельности, затем вместе.
4. Проверь, что шесть точек EQ можно перемещать и менять Q через панель DETAIL SETTINGS.
5. Проверь Save Preset / Load Preset.

**Предупреждение:** усиление EQ +36 dB экстремально; используй с запасом по громкости, чтобы не перегружать сигнал.

## Лицензии

Для исходников используется JUCE 8.0.7, которая скачивается при сборке. При распространении продукта соблюдай соответствующие условия лицензии JUCE. Изображение встроено по твоему референсу; права на его использование и распространение остаются за владельцем изображения.
